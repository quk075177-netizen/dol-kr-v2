## post 후처리 (PO1 통합 결과)

- `이(가)` 계열 비정형 표기 → `{{post:...}}` 정규화 → 정적 치환:
  **processed adhoc 잔존 0** (209유닛 전체). raw LLM 출력에는 28건이
  있었지만 전부 정규화됨 — normalize가 안전망으로 작동.
- 정적 치환 예: "오션 브리즈 카페{{post:은는}}" → "오션 브리즈 카페는"
- 동적 마커(런타임 대상) 분포: 은는 60, 을를 49, 이 23, 의 7, 이가 5,
  으로로 3, 와과 2, 아/에게/도/에서 각 1
- 표 외 이름(`이`, `아`)은 이가/이다/아야 중 어느 계열인지 모호하므로
  보존 → PO2 런타임 helper가 전체 `trPostsList`로 처리해야 함
- 발견·수정 버그 3건: `으로로` 받침O "밥으" 오류, 표 외 마커 조용한 삭제,
  `{{post:이/가}}` 이중 중첩 — 모두 `translation/post.py`에서 수정,
  테스트 143개 통과

## 품질 발견 (매크로 조각·문법)

1. **placeholder 뒤 단일 추측 조사 광범위** — 프롬프트 규칙 9(마커 필수)의
   준수율이 부분적. raw 기준 combat 78건, gwylan 110건, cafe 8건:
   ```text
   <0001071>를 던진다      ← 을/를 마커 없이 "를"로 확정 (받침 추측)
   <0001183>가 말한다      ← 이/가 마커 없이 "가"로 확정
   ```
   받침을 잘못 추측하면 게임에서 어색한 문장이 되므로, 추후 대응 필요
   (마커 준수 프롬프트 강화 또는 "placeholder 뒤 단일 조사" 검출 →
   재시도/리뷰 플래그).
2. **매크로 조각 삽입 어색 사례** (P1 수집 목표):
   ```text
   <0000051>{{post:은는}} <0000052>{{post:을를}} <0000053>{{post:은는}}
   <0000054>{{post:은는}} 하지만
   ```
   매크로가 문장을 조각조각 조립하는 전투 묘사로, LLM이 마커를 이어붙인
   형태. 문장 유닛 단위로는 자연스러운 한국어로 재구성 불가 — 시맨틱 롤
   없이 해결 불가능한 구조이지만, 이는 원문 구조의 한계로 **롤 계층
   도입 근거로는 부족** (발생 빈도 낮음, 수동 보정 가능).
3. **인명 표기 비일관** — Gwylan이 passage 내에서 글윌란/귀란/글란/
   귈란/글이란 5가지로 번역됨. NPC 인명 glossary 또는 few-shot 지시 필요.
   Sam→샘, Robin→로빈은 일관.
4. **UI/설정**: 버튼 라벨·구조 유지 우수. Settings는 placeholder 위주
   유닛이라 구조 보존이 중심.
5. **어휘 미번역 잔존** — "grim fascination" 등 일부 표현이 영어로 남음.
   전투 특수 표현 glossary(후순위 데이터 항목)와 연결되는 사례.
